# Documentation · Dokumentation

The documentation of SuperAgent comes with the extension, in two languages with
the same pages. English is the reference language.

Die Dokumentation von SuperAgent liegt der Erweiterung bei, in zwei Sprachen
mit denselben Seiten. Leitsprache ist Englisch.

| Language · Sprache | Start here · Hier beginnen |
| --- | --- |
| English | [docs/en/README.md](en/README.md) |
| Deutsch | [docs/de/README.md](de/README.md) |

Who reads what · Wer was liest:

- Installing and setting up (agency, administrator): installation, setup,
  permissions, customising, how the assistant works, privacy, troubleshooting.
- Setting up assistants and their texts (editors): usage.
- Installieren und einrichten (Agentur, Administrator): Installation,
  Einrichtung, Rechte, Anpassen, So arbeitet der Assistent, Datenschutz,
  Fehlersuche.
- Assistenten und ihre Texte einrichten (Redaktion): Bedienung.
