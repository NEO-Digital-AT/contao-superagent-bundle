# SuperAgent – documentation

SuperAgent adds an AI chat assistant to a Contao website. A chat button opens a
window in which visitors ask questions; a language model answers from the
knowledge source of the website (its `llms.txt`, a text or a file) and the
questions and answers entered in the back end. With a licence the assistant
also opens pages, forwards requests to the team, searches approved websites,
uses tools of connected MCP servers and installed skills, and takes voice
input.
