# Changelog

All notable changes to this extension are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-11-18

### Fixed
- Without the connections of the licence (no licence, a lower edition, or a licence that no longer covers the website), the results of connection tools kept in the memory of a running conversation and the proof of an earlier guest check no longer reach the model; the licence of each request decides.
- A forwarded request no longer reports "sent" when it cannot go out: without a sender configured (`MAILER_FROM` or `neo_super_agent.from_email`) the e-mail address of the website administrator of the start point is the sender, else the one of the system administrator, as for Contao's own e-mails; without any of them the chat shows its error notice and the log names the reason (before, the mailer dropped the message later without a sender). The assistant's form warns in **Escalation & consent** which start points have no sender.

## [1.0.0] - 2026-11-13

Initial release. Runs on Contao 5.3 to 6.0 with PHP 8.2 to 8.5, as far as the Contao version supports it (Contao 5.7 needs PHP 8.3, Contao 6.0 PHP 8.4).

### Added
- Formatted replies: the assistant writes Markdown, which the chat window shows safely (built from text nodes, links only to web, mail and phone addresses): bold, lists, tables (bookings, offers, rooms and prices; shown row by row where the window is too narrow) and a link alone in its line as a button, e.g. **Pay now** for a payment link.
- An assistant has one language: one language record with greeting, starter questions and texts (a new assistant gets the first language of the website; no second record can be added). A website with several languages has an assistant per language.
- AI chat assistant: a chat button opens a window in which visitors ask questions; a language model answers from the knowledge source of the website (its `llms.txt`, a text or a file) and the questions and answers entered in the back end. The window always says that visitors write with an AI (EU AI Act, Art. 50).
- Name, image, model, answer style and texts per language in the back end, with default texts in eleven languages; the conversation stays open across pages. The assistant remembers the conversation: the last 30 messages, and the results of the tools of connections and the skills it loaded travel with the conversation, encrypted in the visitor's browser tab, nothing stored on the server; a booking made in the chat is known in the next messages.
- Safety rules on by default: no medical advice, a privacy mode that removes personal data before anything goes to the AI service. A place, a country or an address without a person's name is no personal data, so questions about the weather or the way there work in privacy mode.
- Skills and tools: the assistant opens pages, prefills the forwarding form to the team, searches approved websites, uses tools of connected MCP servers and installed skills. Tools of connections need a strong language model: the assistant's form names the models tested with the booking flow of the apaleo template and says whether the chosen one is among them. While a tool looks something up, the sentence the model writes with the call ("One moment, I am checking …") appears at once as its own message; the answer follows. Tools with an input for a person (e-mail address, phone number, first or last name, or a name or address described as a person's) are marked "needs personal data"; the name of a place is not. Tool descriptions keep empty schemas as objects (AI services refuse the whole request otherwise, e.g. for apaleo's UpdateReservation); a tool whose description the AI service still refuses is left out alone and shown in the tool log. The prompt names the weekday of today and of the next 14 days. The catalogue lists only the tools still to load; loading a tool again answers that it is offered and must be called, so models with many tools no longer spend their steps loading. A tool error makes the model correct its arguments and call again before it offers the team. With personal data masked, a tool that changes data does not run with masked values (no booking with a placeholder as contact).
- Connection templates, shipped with apaleo (sign-in at apaleo's MCP server with automatic registration, no app of your own; it asks for the permissions its tools need: property, availability, offers, reservations, folios and invoices): a guest check before the tools of a reservation, setup steps and skills for booking (an address and phone number the visitor gives are entered, with the country taken from postal code and city and the phone number in international format; a prepaid or non-refundable rate gets its payment link with the confirmation), changes, payment links, cancellation and invoices (installed with the connection; a new text of the template is taken over by the database update after an update or when the connection is saved); files from tools (e.g. an invoice) are downloaded in the chat and not passed to the AI service.
- Waits for the consent of a consent tool; rate-limited endpoints; overridable template, design through CSS variables.
- Free as a chat with a credit line; a licence removes the credit line and adds, per edition, page navigation, forwarding and web search (Basic), MCP servers and skills (Plus) and voice input (Pro).
- The chat button takes part in the **buttons at the edge of the screen** of NEO Basic (`data-neo-dock` attributes): with buttons of other extensions in the same corner (cookie settings, accessibility panel) it becomes an entry of one settings button with a menu, or is stacked with them, as set in the page layout; the window opens next to the settings button or the chat button, and the focus goes back to where it was when the window opened. The setting **Position** is the corner of the chat button. Websites that override `frontend_module/neo_agent.html.twig` take over the `data-neo-dock*` attributes and `template[data-neo-dock-icon]`; without them the chat button keeps its own place.
- Back end in eleven languages; documentation in English and German; unit tests.

After installing: update the database, enter the AI connection under **NEO Digital › Access keys and licences** and confirm the terms.
